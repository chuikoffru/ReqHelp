# ТЗ-Ассистент — расширение Chrome

Требуется Chrome 116 или новее.

1. Запустите сайт: `npm run dev` и войдите на http://localhost:5173
2. Откройте `chrome://extensions`, включите «Режим разработчика»
3. «Загрузить распакованное расширение» → папка `extension/`
4. Нажмите «Обновить» на карточке расширения. Если Chrome спросит доступ к сайтам — разрешите все сайты (иначе текст читается только с localhost).
5. На странице с ТЗ нажмите иконку расширения или пункт «Проанализировать ТЗ» в контекстном меню
6. PDF и локальные файлы Chrome часто не отдаёт скрипту: выделите текст или вставьте его в панель вручную
